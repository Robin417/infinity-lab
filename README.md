# INFINITY LAB

업로드한 디자인을 참고한 반응형 정적 홈페이지. 별도 패키지 설치나 빌드가 필요 없습니다.

## 구성
- `dist/index.html`: 전체 페이지와 스타일, 문의 파일 다운로드 동작
- `dist/assets/hero.webp`: AI로 재구성한 카페 배경 이미지
- `.github/workflows/pages.yml`: main 브랜치 변경 시 GitHub Pages 배포

## GitHub Pages
새 저장소에 전체 소스를 올린 다음 Settings → Pages → Build and deployment → Source에서 GitHub Actions를 선택하세요. main 브랜치 push 또는 Actions 수동 실행으로 배포합니다.

## 문의
현재 운영용 연락처가 제공되지 않아 문의 내용은 서버로 전송하지 않고 방문자 기기에 txt로 저장합니다. 실제 문의 접수에는 이메일 또는 서버 연결이 필요합니다.

## 이미지
제공된 화면을 참고하여 이미지 생성 도구로 만든 새 사진입니다. 이미지 프롬프트는 AI_ASSET_PROMPT.txt에 기록되어 있습니다.
